# Evidências cross-source

A opção **Evidências cross-source** executa consultas independentes em MOS,
Leiaute e XSD e exibe um bloco para cada fonte. Ela permite observar cobertura
complementar sem misturar a autoridade das famílias.

!!! info
    Esta opção não é “Consulta Completa” e não gera conclusão automática. Uma
    síntese livre entre fontes é uma evolução futura da experiência pública. Essa
    delimitação é do escopo operacional do menu, não ausência de Complete Mode na
    arquitetura do repositório.

Uma fonte pode não ter evidência e as demais ainda retornarem resultados. A
ausência é informada por fonte; não é tratada como falha técnica.
