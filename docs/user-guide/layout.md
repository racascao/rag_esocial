# Consultar o Leiaute

Use **Leiaute** para navegar eventos, grupos e campos. Perguntas podem indicar
um evento S-XXXX, um nome técnico e atributos como ocorrência, condição, tipo,
tamanho e decimais. Relações de pai e filhos são recuperadas pela árvore
estrutural materializada, não apenas por texto em descrições.

Exemplos: “quais campos pertencem ao grupo ideEmpregador no S-1000?”, “qual a
condição do grupo?” e “qual o tamanho do campo nrInsc?”. O path completo evita
confundir nomes repetidos em ramos ou eventos diferentes.

Veja [estrutura do Leiaute](../layout_structure.md) para o contrato de parser.
