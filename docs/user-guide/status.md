# Status

A opção **Status** separa informações em visão geral, runtime e corpus. Ela
mostra versões humanas do MOS/Leiaute/XSD, o ID do build, parser revision,
search revision, geração do runtime, snapshot e quantidade de artefatos.

Esses dados são diagnósticos: eles explicam qual cadeia está ativa, mas não são
necessários na consulta diária. A interpretação detalhada está em
[Diagnóstico](../operations/diagnostics.md).
