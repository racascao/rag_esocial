# Consultar o MOS

Escolha **MOS** para conceitos, procedimentos, prazos, obrigatoriedade e
orientações textuais. O corpus materializa seções por evento, blocos de
metadata, tópicos e subitens; a interface informa qual unidade foi encontrada.

Exemplos: “qual é o conceito do evento S-1000?”, “quem está obrigado?” e “qual
é o prazo de envio?”. Quando não houver evidência autorizada para a consulta, a
resposta correta é uma abstenção visual — não um erro nem uma resposta estimada.

Para a estrutura técnica do parser, consulte [estrutura do MOS](../mos_structure.md).
