# Atualizar versão

Selecione **Importar nova versão** apenas quando houver uma atualização oficial
a ser carregada. O fluxo pede as três URLs principais, descobre anexos,
valida artefatos e prepara uma nova cadeia versionada antes da ativação.

O runtime anterior permanece utilizável até que o novo snapshot, build e índices
atinjam readiness. Uma falha na preparação não troca o runtime ativo. Mais
detalhes operacionais estão em [Atualização](../operations/version-update.md).
