# Fontes e autoridade

A autoridade é definida pelo tipo de afirmação, não por uma ordem fixa entre
fontes.

| Fonte | Autoridade principal |
| --- | --- |
| XSD | forma XML, tipos, cardinalidade, enumeração, pattern e estrutura schema |
| Leiaute | condição funcional, grupos, campos, ocorrência e regras documentais |
| MOS | conceitos, procedimentos, prazos, obrigatoriedade e orientação textual |

Não existe uma regra simplista “XSD > Leiaute > MOS”. Divergências e limites
continuam visíveis; a opção cross-source não fabrica consenso.
