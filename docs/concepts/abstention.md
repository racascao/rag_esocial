# Abstenção

Abstenção não é erro. Ela ocorre quando nenhuma evidência autorizada é
localizada, quando o suporte requerido não existe ou quando uma relação não pode
ser resolvida deterministicamente. Na interface, ela aparece como aviso claro,
não como falha operacional.

Erros técnicos — como URL inválida ou falha de preparação — têm apresentação
separada. Essa distinção evita que ausência de suporte seja interpretada como
autorização para responder por estimativa.
