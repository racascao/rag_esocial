# Interface do terminal

O menu apresenta MOS, Leiaute, XSD, evidências cross-source, atualização e
Status. A interface Rich organiza cada evidência em um painel que mostra o
conteúdo estrutural autorizado, a fonte, o path citável e o score de busca.

Na opção cross-source as famílias aparecem em blocos independentes. Uma fonte
sem resultado exibe uma mensagem de ausência de evidência, sem invalidar os
resultados das outras. Cores ajudam a leitura, mas nenhuma informação essencial
depende delas.
