# Visão geral

O produto é CLI-first: a experiência normal começa em `./esocial`. Ele executa
localmente, em containers, e mantém a proveniência dos documentos oficiais
importados. O usuário não precisa conhecer IDs, builds ou revisões internas para
consultar o corpus.

O sistema usa três famílias: **MOS** para orientações e prosa operacional,
**Leiaute** para eventos, grupos, campos e regras funcionais, e **XSD** para a
forma XML. A autoridade depende do tipo da afirmação; uma fonte não substitui
automaticamente a outra.

Veja também [fontes e autoridade](../concepts/sources-and-authority.md).
