# Avaliação

O projeto mede retrieval, evidence assembly, contratos de resposta e Complete
Mode com benchmarks versionados. Avaliações automáticas medem estrutura,
proveniência e política; não substituem revisão humana semântica ou jurídica.

Os benchmarks congelados impedem resultado favorável por alteração retrospectiva
do conjunto avaliado. Veja [Q14](q14.md), [Complete](complete.md) e
[métricas](quality-model.md).
