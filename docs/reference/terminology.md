# Terminologia

| Termo | Significado |
| --- | --- |
| `DocumentArtifact` | Arquivo oficial capturado, com hash e origem. |
| `DocumentVersion` | Versão de uma fonte individual. |
| `CorpusSnapshot` | Conjunto congelado de versões e papéis de artefato. |
| `CorpusBuild` | Materialização de snapshot para parser/configuração. |
| `SearchProjection` | Índice de busca de um build e revisão. |
| `ActiveRuntime` | Ponte para build/projection operacionais. |
| `CitationTarget` | Origem estável e citável. |
| `SearchUnit` | Unidade indexada para retrieval. |
| `EvidenceUnit` | Unidade autorizada da cadeia de evidência. |
| `SourceFact` | Fato extraído com origem e build. |
| `FactResolution` | Resultado por RequestedFact e fonte. |
| source-local stable path | Caminho local estável da origem documental. |
| D1/D2/D3 | Determinismo nativo, documental e por travessia. |
| abstention | Resultado sem suporte autorizado, não erro. |
