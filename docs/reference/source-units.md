# Unidades das fontes

MOS usa seção de evento, metadata, tópico, tópico de evento, subitem e blocos
de conteúdo. Leiaute usa evento, grupo e campo. XSD usa schema de evento,
elemento, tipo compartilhado e enumeração.

Essas unidades são diferentes de `SearchUnit`: o índice pode representá-las para
busca, mas a entidade estrutural e a citação preservam origem independente.
Detalhes: [modelos das fontes](../architecture/source-models.md).
