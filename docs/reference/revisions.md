# Revisões

`parser-suite-v2` identifica a revisão atual de parser estrutural. A revisão de
busca atual é `fts-baseline-v3`. Elas não são intercambiáveis: parser transforma
snapshot em build; search cria projections derivadas de build.

Uma atualização de fonte oficial também é distinta de ambas. A versão de fonte,
snapshot, build e runtime devem ser observados como camadas separadas.
